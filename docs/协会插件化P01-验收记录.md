## 1. 本批改动

1. **协会声明插件化**：`src/shared/associations/` 新增 `base.js` + `registry.js` + 六个协会插件（pkb/tt/bd/tn/bk/fb）；`utils/associations.js` 改为兼容转发，三端 md5 一致。
2. **运动标识接入**：`team-service.js` 四处 `football11` / `football` 二元硬编码改为 `sportKeyOf(association)`，足球插件补 `sportKey: 'football'`。
3. **主题变量接线（本次修复缺口 1）**：`branding.js` 新增 `currentThemeStyle()`；`association-home` 与 `my-sports` 两个宿主页面在 `setData` 时写入 `themeStyle` 并在根容器挂 `style="{{themeStyle}}"`。CSS 变量沿节点继承，动态注册、app.wxss 尚无 `.assoc-<id>` 类的协会也能立即拿到主题色——"新协会免手改 app.wxss"的收益从此兑现。
4. **规则快照契约（本次修复缺口 2）**：`validateAssociationPlugin` 按运动类型校验——球拍运动必须有 `format.defaultFormat` / `elo` / `ratedPairLimit`，团队运动必须有 `teamSportFormat` 与至少一个 `xxxRules` 规则快照；动态注册走同一契约，杜绝"能注册但抽签时静默套错赛制"的插件混入。
5. **专项测试**：`tests/association-plugin-registry.test.js` 由 5 条增至 7 条，新增契约拒绝用例与宿主页面接线断言。

## 2. 关键口径

- **动态插件是单端实例**：`src` 与 `miniprogram/shared` 各持一份注册表，运行时动态注册只在注册的那份实例生效，不跨端同步。动态注册目前仅供契约/扩展测试，生产路径仍以六个内置插件为准；测试据实只校验生成能力，不跨端断言。
- **`defaultFormatOf` 的兼容回落保持不变**：团队运动本就没有 `format`（走 `teamSportFormat` + 规则快照），未知 id 回落球拍默认赛制是历史兼容路径；真正的防线前移到注册契约——球拍插件缺 `format` 现在直接被拒，不会再静默套错。
