## 1. 本批改动

1. **团队运动档案指标声明扩展（`SportAdapter.view.profileStatColumns`）**：
   - `src/shared/sports/contract.js` 为 `createSportAdapter` 补齐 `profileStatColumns` 默认回落，并在 `validateSportAdapter` 校验数组元素 `key` / `label`。
   - `src/shared/sports/basketball/adapter.js` 与 `src/shared/sports/football/adapter.js` 各自声明个人成绩档案列；`miniprogram/utils/team-profile-view.js` 改由 `getSportAdapter(profile.sportFormat)` 声明渲染指标列，消除 `FOOTBALL_FIELDS` / `BASKETBALL_FIELDS` 与 `=== 'football11'` 分支。
2. **球拍运动 `ScoringAdapter` 轻收口（`src/shared/sports/racket/`）**：
   - 新增 `point.js`（两层分制：`局`）、`tennis.js`（三层网球：`盘`、`usePointTextClass`）与 `registry.js`（`validateScoringAdapter` / `getScoringAdapter` / `listScoringAdapters` / `registerScoringAdapter` / `unregisterScoringAdapter`）。
   - `miniprogram/services/match-entry-view.js`、`miniprogram/packageEvent/match-entry/match-entry.js`、`miniprogram/services/live-view.js`、`miniprogram/packageTeam/live-score/live-score.wxml` 全部改由 `getScoringAdapter(...)` 驱动（保留 `isTennis`、`scoreUnit` 等向后兼容字段）。
3. **前端团队运动通用页面声明驱动**：
   - `miniprogram/packageTeam/team-event-detail/team-event-detail.js`、`miniprogram/packageTeam/team-event-list/team-event-list.js`、`miniprogram/packageTeam/my-team-profile/my-team-profile.js`、`miniprogram/packageTeam/team-detail/team-detail.js` + `.wxml`、`miniprogram/templates/personal-sports-client.js` 改调 `getSportAdapter` / `getSportAdapterFor` 读取 `eventFormMode`、`recordPageUrl`、`liveScorePageUrl`、`recordHintText`，消除通用页面的 `=== 'football11'` 及硬编码跳转 URL（足球专属页面 `football-match.js` 与 `football-event-form.js` 保留职责边界）。
4. **新增开闭原则端到端实证与守卫测试（`tests/plugin-open-closed-e2e.test.js`）**：
   - 球拍 `ScoringAdapter` 契约与 `match-entry-view` / `live-view` / `teamProfileView` 动态插件回归（3 条）。
   - **虚拟第 7 协会闭环实证（1 条）**：不改动任何一行内核代码，动态注册虚拟排球协会 `vb_e2e`（`AssociationPlugin` + `SportAdapter` + `ServerSportPlugin`），在内存仓储完整跑通 **建队 → 审批 → 建赛 → 报名 → 审核 → 锁名单 → 抽签 → 录分 → 发布 → 自定义积分榜 → 结算 → 球队战绩 → 我的团队档案** 全链路，并在 `finally` 干净注销。
   - **前端插件化静态守卫（1 条）**：锁定 10 个前端通用页面/视图文件不再出现 `=== 'football11'`、`=== 'tennis'` 或硬编码 `/packageTeam/football-match/`。
