## 3. 关键口径

1. **首页 BFF 降级与游客边界**：`loadSchoolHomeView` 优先走 `getSchoolHomeSummary`（1 次云调用）；若注入旧多接口测试替身或显式设置 `HOME_BFF=off` / `useBff: false`，自动回退原多接口聚合路径。游客只读公告，跨校只读返回真实空聚合。
2. **`readMatchPage` 计数收敛**：首屏/无 `cursor` 时返回精确 `total` 与 `pendingCount`；带 `cursor` 续页翻页（且未显式要求 `includeCounts: true`）时跳过 2 次冗余 `count` 聚合，返回 `total: null, pendingCount: null`。
3. **脱敏与 UGC 开关**：`PRIVACY_MASK` 与 `UGC_SAFETY` 默认开启（设为 `off` 关闭）；跨校只读普通昵称脱敏由 `PRIVACY_MASK_PUBLIC=on` 按需开启；云端微信内容安全由 `UGC_WECHAT_CHECK=on` 激活。
4. **榜单实名按角色脱敏（D2 收尾补接线）**：`school-rank-service.js` 的三个公开 DTO 出口（`buildRows` 榜单行、`memberStatsRow` 成绩行、`getSchoolMemberProfile` 个人档案）统一接入 `maskRealName`——普通成员视角只拿脱敏实名（如 `王*明`），**本人与审核角色保留完整值**，学号仍严格限本人/管理员。前端 `rank-view.js` 用 `realName` 做搜索匹配，脱敏后仍可按姓氏/末字命中，完整姓名搜索由昵称承担。
   - 背景：`privacy-mask.js` 的工具函数虽已单测覆盖，但初版只接在名册列表一处，榜单路径仍直出完整 `realName`；新增的是**走真实 handler 的 DTO 接线测试**（不同于纯函数单测），锁死"哪些出口真接了管道"。
   - 读量不受影响：`canSchoolAction` 为纯字段判断，不加任何仓储读；`rank-read-budget` / `profile-read-budget` 全部保持通过。
