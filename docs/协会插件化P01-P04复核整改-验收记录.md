# 协会插件化 P01–P04 复核整改验收记录

## 2. 本批完成

- P01 校验规则快照的运动格式和配对双方的 `sportKey`。完整性测试双向检查协会和适配器，并验证联合注册失败时回滚。
- P02 为规则归一化异常补回归断言，设计文档订正注册表查询名称和录分路由接口。
- P03 订正账本口径。当前有 7 处 `getSportAdapterFor` 调用，另有模块级动作分派包装。P02 的 `8554062` 提供契约、适配器与服务端注册表，默认钩子工厂由 P03 的 `bcccd68` 新增。
- P04 校验统计列条目及唯一键，恢复篮球球员榜的场均得分。虚拟协会从小程序建赛页选择非默认预设，提交到服务层后继续完成赛程、录分、结算及战绩流程。

## 3. 关键口径

新增团队协会的规则快照须声明 `sportFormat`。球员榜可声明 `view.playerStatColumns`，省略时沿用单场统计列。篮球的场均得分为服务端派生值，只出现在球员榜。

## 4. 踩坑与纠正

全量复跑发现旧足球夹具临时把篮球协会的格式改为足球，造成运动标识不匹配。改由已登记的足球协会执行业务用例。
