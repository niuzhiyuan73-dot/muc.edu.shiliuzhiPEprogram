# 管理员评级调整复核验收记录

## 1. 元信息

2026-11-25。复核基线 `182a53f`，开工前全量通过 217 个文件、3,455 条用例。

## 2. 本批完成

- 表单拒绝空目标分，允许明确输入 0。相同内容重试沿用请求编号，编辑后提交使用新编号，成功提示显示服务端确认的分数。
- 云端只对同一操作者、会员、评级池、目标分与原因返回幂等结果。事务内复核目标账号状态、学校归属和学籍。
- 个人档案按当前项目展示比赛结算与管理员调整。管理员调整按范围序号插入曲线并用方框标记，原因和操作者只保留在审计记录中。

## 3. 关键口径

单场最大涨跌与逐场战绩按比赛计算。调分记录查询按学校、协会和会员约束，复用 `rating_adjustments.by_scope_user`。

## 4. 踩坑与纠正

空字符串在转换后会成为合法的 0。响应丢失后的旧请求编号只能用于原操作。档案未指定项目时，服务端沿用页面的单打优先约定，避免曲线和选中项目错开。

## 5. 验证结果

常规与严格仿真全量各通过 217 个文件、3,458 条用例，零失败、零超时。客户端共享文件 61 个与云端镜像 126 个一致，部署预检和 5 项验收探针通过。
