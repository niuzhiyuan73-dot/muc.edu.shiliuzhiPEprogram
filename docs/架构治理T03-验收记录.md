## 3. 关键口径

1. **生产客户端不再内置本地模拟仓储**：`school-mock-loader.js` 仅通过 `registerMockProvider` 注入；测试环境由 `tools/run-tests.js`（`--require tests/helpers/register-mock.js`）与 `tests/helpers/page-harness.js` 自动注入；生产包彻底不包含 `src/mock/` 与 `src/server/`。
2. **外校只读静态示例保留在客户端**：`miniprogram/services/school-demo.js` 无任何服务端或内存仓储依赖，服务于云端模式下浏览未入驻示例学校（北航）的只读预览，保留在主包。

## 4. 踩坑与纠正

- 组件拆分初期，`match-actions.js` 漏带局部常量 `ACTION_TEXT`、`association-space-panel.js` 外壳漏带 `ANNOUNCEMENT_CATEGORIES` 与 `PICK_POOL`，导致 `page.test.js` 中 14 条装配用例报错，补回局部引用后全部通过；
- `tests/meet-seed-cache.test.js` 与 `tests/g1-repo-resilience.test.js` 各有一处 `require.resolve` / `path.join` 硬编码旧 `miniprogram/services/` 路径，已同步指向 `src/mock/`；
- 验收复核发现 G2b 剥离 Mock 后的两处残留语义：`config.example.js` 仍称"留空即退回本地模拟数据、功能完整可演示"，`app.js` 仍打印同类提示。已改为明确"留空进入 MOCK 模式、真机需填 `CLOUD_ENV_ID`，Mock 仅由测试注入提供"。
